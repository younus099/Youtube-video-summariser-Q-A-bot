# YouTube Summarizer & Q&A Assistant

A full-stack AI web application that analyzes YouTube videos using transcripts.

## Features

- Extracts YouTube video transcripts
- Generates AI-powered summaries using Gemini API
- Answers user questions from transcript context
- Displays embedded YouTube video player
- Provides timestamp-based responses

## Tech Stack

### Frontend
- React
- Axios

### Backend
- Node.js
- Express.js

### AI / APIs
- Gemini API
- YouTube Transcript API
